const bool use_row,
const tatami::VectorPtr< Index_ > & indices_ptr,
const TestAccessOptions & options )

Test unsorted sparse access to an indexed subset of a row/column. Any discrepancies between sorted and unsorted accesses on matrix will raise a GoogleTest error. This function is intended for tatami::Matrix subclasses where tatami::Options::sparse_ordered_index = false has an effect.

When testing subclasses implementing delayed operations, we recommend wrapping the seed(s) with ReversedIndicesWrapper instances before calling this function. This ensures that unordered access in the seed is handled correctly.

Template Parameters
Value_Type of the data.
Index_Integer type of the row/column index.
Parameters
matrixMatrix for which to test access.
use_rowWhether to test row access. If false, column access is tested instead.
indices_ptrPointer to a vector of sorted and unique indices on the non-target dimension. These are the columns if use_row = true and the rows otherwise.
optionsFurther options for testing.
